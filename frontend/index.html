Separate instruction and data memories with independent buses.

  • Instruction fetch and data access can overlap.
  • No shared-port serialization in this benchmark.

Instruction and data transactions share one memory port.

  • Fetch and load/store are serviced in separate cycles.
  • Shared-bus arbiter behavior is available as a test target.
